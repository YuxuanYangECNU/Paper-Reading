光学论文 · 阅读工作流与 8 色标记

用于 optics / photonics / metasurface 等英文论文。颜色按“信息类型”固定，阅读顺序按“先全局、再原理、后细节”执行。

原则：颜色不要随论文改变；不要见到关键词就画，而要判断这句话在整篇论文中承担什么作用。目标不是“画得多”，而是以后翻开 PDF，几分钟内恢复整篇论文的逻辑。

8 色固定含义

颜色 固定含义 阅读时问自己
红色 Problem / Gap / Limitation 为什么要做？现有方法哪里不够？还有什么问题没解决？
黄色 Novelty / Core Claim / Conclusion 这篇真正新在哪里？作者由结果得出的核心结论 / capability claim 是什么？
绿色 Function / Physical Mechanism / Core Method 这个东西具体干什么？它如何工作？核心物理过程是什么？
蓝色 Implementation / System / Device 客观上用了什么、搭了什么？器件、模块、光路、结构和参数是什么？
紫色 Theory / Equation / Model 哪个数学关系支撑这个机制？数学骨架是什么？
粉色 Result / Evidence / Performance 具体实验 / 仿真得到了什么？有哪些定量性能、对比和实际能力？
橙色 My Insight / Connection / Inspiration 对我的课题、未来方向、写作或套磁有什么用？
灰色 Background / Related Work / Secondary Info 这是帮助理解领域脉络、但不是本文核心的信息吗？

不同部分的主色

快速记忆： Abstract：红 + 黄 + 蓝 + 粉； 原理 / 主图：蓝 + 绿； 理论：绿 + 紫； 实验结果：粉 + 黄。 红用于问题 / 局限，橙用于自己的启发，随时出现。

面对一篇新论文：固定工作流

STEP 1 Title → Abstract → Conclusion

先建立全局认识，不碰细节。

  • 研究对象是什么？
  • 红色：为什么要做？现有方法有什么问题？
  • 黄色：作者提出了什么新东西？核心 claim / capability 是什么？
  • 蓝色：系统 / 器件 / 实现框架是什么？
  • 粉色：最后实际实现了什么？有哪些定量性能、对比结果或 prototype 能力？
优先标记：ProblemNoveltyImplementationResultConnection

Abstract / Conclusion 标记原则：通常以 红、黄、蓝、粉 为主。蓝回答“系统是什么 / 做了什么东西”，绿回答“它具体干什么 / 如何工作”，粉回答“实际做到了什么 / 性能多好”，黄回答“作者由这些结果得出了什么核心 claim / conclusion”。紫色一般少用，除非摘要中直接给出支撑全文的核心理论模型 / 方程。

STEP 2 Figure 1 / Concept Figure → 快速扫所有 Figures

先看图建立物理图景。主要在 caption 上标记，图本身只做极少量注释。

  • 先不标色：确认 Input → System / Device → Output，以及每个 panel 分别在讲什么。
  • 蓝色：客观上“是什么 / 搭了什么 / 用了什么”——器件、模块、网络、光路、结构、组件。
  • 绿色：这些东西“干什么 / 怎么工作”——提取、生成、调制、衍射、投影、耦合、融合、转换等功能与物理过程。
  • 绿色：核心操控自由度与机制——phase、polarization、wavelength、mode、k-space 等如何被利用。
  • 粉色：如果 caption 已经给出实验结果、性能或某张图证明的 evidence，再标粉色。
主色：What is built / usedWhat it does / How it worksResult（按需）

Figure 标记原则：原理展示和主图概念图通常以 蓝色 + 绿色 为主。蓝色回答“系统里有什么”，绿色回答“它有什么作用、为什么能工作”。

STEP 3 Introduction：Existing Field → Gap → This Work

不要逐句精读，重点找文章存在的理由。

  • 灰色：这个领域现在通常怎么做？
  • 红色：已有方法的关键 limitation 是什么？
  • 红色：作者为什么认为需要新的方案？
  • 黄色：本文到底填补了哪个 gap？
优先标记：BackgroundGapContribution
STEP 4 Principle / Theory：真正搞懂“为什么能工作”

把物理过程压缩成：Input → System → Physical Mechanism → Output。

  • 蓝色：参与原理的关键模块 / 器件是什么？它们如何连接？
  • 绿色：每个模块具体做什么？系统对光场做了什么变换？
  • 绿色：哪些量发生耦合、投影、干涉、传播、调制或转换？
  • 绿色：核心自由度是什么？为什么利用这些自由度就能实现目标功能？
  • 紫色：哪一个公式 / 模型如果不懂，就解释不清这个机制？
主色：SystemMechanismTheory
STEP 5 Device / Methods：只记值得以后回查的细节

不要把 Methods 全部涂满。

  • 蓝色：wavelength、NA、material、period、geometry
  • 蓝色：fabrication、optical setup、optimization / inverse design
  • 蓝色：measurement condition、重要实验参数
  • 蓝色：以后如果要复现、比较或引用，这个数据会不会再回来找？
优先标记：Implementation
STEP 6 Results：建立 Claim ↔ Evidence

结果部分以粉色 + 黄色为主：先找证据，再找作者由证据得到的结论。

  • 粉色：实验 / 仿真具体得到了什么？核心 proof-of-concept、曲线、图像、定量数据和实际 prototype 能力是什么？
  • 粉色：效率、精度、串扰、带宽、通道数、速度、能耗等性能做到什么程度？
  • 黄色：作者如何概括这些结果？支持了哪个核心 claim、capability 或 conclusion？
  • 红色：有没有性能下降、trade-off、异常、局限或尚未解决的问题？
  • 蓝色：只有当测试条件 / 实验设置对理解结果很重要时，标关键条件和参数。
  • 绿色：如果作者解释“为什么会出现这个结果”，把背后的物理机制标成绿色。
主色：Evidence / PerformanceClaim / ConclusionLimitation（按需）

Results 标记原则：粉色回答“数据是什么”，黄色回答“数据说明了什么”；红色找问题，绿色只用于结果背后的机制解释。

STEP 7 最后只看橙色：把论文变成自己的东西

橙色不是作者的信息，而是“这篇论文对我有什么用”。

  • 橙色：能不能借鉴它的物理机制、实验结构或评价指标？
  • 橙色：有没有适合自己论文的叙事方式或理论表达？
  • 橙色：和自己的研究方向有什么直接联系？
  • 橙色：如果调研导师：这篇工作和我的经历如何自然连接？
  • 橙色：有没有新的研究问题或可延伸方向？
优先标记：Insight / Connection / Inspiration
最容易混淆的 4 种颜色： 蓝 = What it is / What is built； 绿 = What it does / How it works； 粉 = What it achieves / Performance； 黄 = What the authors conclude / Claim。 如果一句话同时包含“系统 + 功能 + 性能 + 结论”，可以拆开分段标色，不要整句只用一种颜色。
读完一篇论文，至少留下 6 个答案：
1. Why：为什么要做？
2. What：真正的新东西是什么？
3. How：核心物理机制是什么？
4. Evidence：作者如何证明？
5. Limitation：还有什么问题？
6. Connection：这篇论文对我有什么用？
建议长期固定：红 = 问题，黄 = 创新，绿 = 原理，蓝 = 实现，紫 = 理论，粉 = 结果，橙 = 自己的启发，灰 = 背景。
