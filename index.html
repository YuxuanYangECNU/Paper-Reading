光学论文 · 阅读工作流与 8 色标记

用于 optics / photonics / metasurface 等英文论文。颜色按“信息类型”固定，阅读顺序按“先全局、再原理、后细节”执行。

原则：颜色不要随论文改变；不要见到关键词就画，而要判断这句话在整篇论文中承担什么作用。目标不是“画得多”，而是以后翻开 PDF，几分钟内恢复整篇论文的逻辑。

8 色固定含义

颜色 固定含义 阅读时问自己
红色 Problem / Gap / Limitation 为什么要做？现有方法哪里不够？还有什么问题没解决？
黄色 Novelty / Core Claim / Contribution 这篇真正新在哪里？作者最想让我记住什么？
绿色 Physical Mechanism / Core Method 它为什么能工作？核心物理过程是什么？
蓝色 Implementation / System / Device 具体怎么实现？器件、光路、结构、参数是什么？
紫色 Theory / Equation / Model 哪个数学关系支撑这个机制？数学骨架是什么？
粉色 Result / Evidence / Performance 作者拿什么证明？性能有多好？
橙色 My Insight / Connection / Inspiration 对我的课题、未来方向、写作或套磁有什么用？
灰色 Background / Related Work / Secondary Info 这是帮助理解领域脉络、但不是本文核心的信息吗？

面对一篇新论文：固定工作流

STEP 1 Title → Abstract → Conclusion

先建立全局认识，不碰细节。

  • 研究对象是什么？
  • 为什么要做？现有方法有什么问题？
  • 作者提出了什么新东西？
  • 最后实现了什么结果？
优先标记：ProblemNoveltyResultConnection
STEP 2 Figure 1 → 快速扫所有 Figures

先看图，建立整篇文章的物理图景和叙事结构。

  • Input 是什么？
  • 经过什么器件 / 系统 / 光学过程？
  • 操控了哪些自由度：phase、polarization、wavelength、mode、k-space…？
  • Output 是什么？
  • 每一张图分别想证明哪个 claim？
优先标记：MechanismImplementationEvidence
STEP 3 Introduction：Existing Field → Gap → This Work

不要逐句精读，重点找文章存在的理由。

  • 这个领域现在通常怎么做？
  • 已有方法的关键 limitation 是什么？
  • 作者为什么认为需要新的方案？
  • 本文到底填补了哪个 gap？
优先标记：BackgroundGapContribution
STEP 4 Principle / Theory：真正搞懂“为什么能工作”

把物理过程压缩成：Input → Physical Mechanism → Output。

  • 核心自由度是什么？
  • 系统对光场做了什么变换？
  • 哪些量发生耦合、投影、干涉、传播或转换？
  • 哪一个公式如果不懂，就解释不清这篇论文？
优先标记：MechanismTheoryImplementation
STEP 5 Device / Methods：只记值得以后回查的细节

不要把 Methods 全部涂满。

  • wavelength、NA、material、period、geometry
  • fabrication、optical setup、optimization / inverse design
  • measurement condition、重要实验参数
  • 以后如果要复现、比较或引用，这个数据会不会再回来找？
优先标记：Implementation
STEP 6 Results：建立 Claim ↔ Evidence

每张结果图都必须能回答：“它在证明什么？”

  • 核心 proof-of-concept 是哪一张？
  • 效率、精度、串扰、带宽、通道数等性能如何？
  • simulation 和 experiment 是否一致？
  • 有没有 trade-off、性能下降或作者没解决的问题？
优先标记：EvidenceConclusionLimitation
STEP 7 最后只看橙色：把论文变成自己的东西

橙色不是作者的信息，而是“这篇论文对我有什么用”。

  • 能不能借鉴它的物理机制、实验结构或评价指标？
  • 有没有适合自己论文的叙事方式或理论表达？
  • 和自己的研究方向有什么直接联系？
  • 如果调研导师：这篇工作和我的经历如何自然连接？
  • 有没有新的研究问题或可延伸方向？
优先标记：Insight / Connection / Inspiration
读完一篇论文，至少留下 6 个答案：
1. Why：为什么要做？
2. What：真正的新东西是什么？
3. How：核心物理机制是什么？
4. Evidence：作者如何证明？
5. Limitation：还有什么问题？
6. Connection：这篇论文对我有什么用？
建议长期固定：红 = 问题，黄 = 创新，绿 = 原理，蓝 = 实现，紫 = 理论，粉 = 结果，橙 = 自己的启发，灰 = 背景。
