光学论文 · 8 色标记规则

用于阅读 optics / photonics / metasurface 等英文期刊论文。每种颜色固定一个含义，快速区分“结论、方法、公式、结果和与你课题的关系”。

怎么用：读论文时只按下面规则高亮。同一种信息始终使用同一种颜色，方便以后快速复习、做组会 PPT 和回查文献。
颜色 标记内容 读到这里时问自己
黄色 核心结论 / Take-home message 这篇文章最后到底说明了什么？
红色 问题 / 局限 / 质疑点 这里有什么限制、漏洞或值得继续追问的地方？
绿色 方法 / 核心思路 / 系统结构 作者是怎么做到的？
蓝色 定义 / 概念 / 物理量含义 这个概念、符号或物理量是什么意思？
紫色 关键公式 / 推导主线 这篇文章的数学骨架在哪里？
粉色 实验结果 / 仿真结果 / 图表结论 支持作者结论的证据在哪里？
橙色 与自己课题直接相关 / 可借鉴 这部分对我的研究有什么用？
灰色 背景信息 / 常识铺垫 / 次重点 这是帮助理解上下文、但不需要重点记忆的信息吗？
固定颜色，不随论文改变。重点不是“多画”，而是“画得准”。
